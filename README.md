## Project Overview

This project contains automated test scripts developed for the **PAI Admin System** using **Selenium WebDriver with Python and PyTest**, following the **Page Object Model (POM)** design pattern.

The automation currently covers the following modules:

* **Home**
* **About**
* **Product**
* **Services**

The test scripts were developed and maintained alongside ongoing **bug fixing and application development**. Therefore, changes to the application's UI, functionality, elements, or workflows may occur in the future. As the system evolves, the automation scripts may require updates to maintain compatibility with the latest version of the application.

### Note

This automation project represents the test coverage implemented during the development and bug-fixing period. Additional test cases and modules may be added, and existing scripts may be modified as the PAI Admin System continues to evolve.
